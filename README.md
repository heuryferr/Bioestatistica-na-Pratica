# Bioestatística na Prática — Vol 1

**Comparando médias** — Dr. Heury Ferr

Livro da série *Bioestatística na Prática*. Este volume introduz os conceitos
fundamentais de testes estatísticos de hipótese e comparação de médias: os
capítulos 1 a 4 formam a base teórica e conceitual; os seguintes mostram a
aplicação prática com ferramentas computacionais.
